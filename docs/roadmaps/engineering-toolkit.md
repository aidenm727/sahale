# Engineering Toolkit Roadmap

The current Atlas contract is [Atlas Architecture](../architecture/atlas.md).
Atlas is a small deterministic repository checker with `bootstrap`, `validate`,
and `sync`. It does not select future work. The previous catalog, reasoning,
readiness, milestone, and convenience-command roadmap is historical and no
longer an implementation target.

The task-context compiler remains a separate implemented library capability.
Its future consumer is a separate owner decision. `tools/generate-context.py`
produces the three registered views used by repository workflows.

Future toolkit work needs a recurring machine-verifiable failure mode and a
concrete consumer under the collaboration standard. This roadmap selects no
checkpoint and grants no implementation, publication, or deployment authority.
