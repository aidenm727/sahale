## Reproducible Candidate Fingerprint

Run the following from the repository root. It includes every path changed
relative to `HEAD`, including deletions and staged changes, plus the two
authorized untracked candidate files. It deliberately excludes the unrelated
untracked internship file. A deleted path contributes a `D` record; a present
regular file contributes its exact bytes and length. The sorted path list is
part of the hash, so adding or removing a candidate path changes the identity.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 - <<'PY'
from hashlib import sha256
from pathlib import Path
import subprocess

root = Path.cwd()
changed = subprocess.run(
    ["git", "diff", "--no-renames", "--name-only", "-z", "HEAD"],
    cwd=root, check=True, capture_output=True,
).stdout
paths = {value.decode("utf-8") for value in changed.split(b"\0") if value}
extra = {
    "docs/reviews/atlas-repository-substrate-simplification-evidence-2026-09-22.md",
    "tests/test_atlas.py",
}
assert all((root / path).is_file() for path in extra)
paths.update(extra)
digest = sha256()
digest.update(b"sahale-atlas-candidate-v1\0")
for relative in sorted(paths):
    path = root / relative
    digest.update(relative.encode("utf-8") + b"\0")
    if not path.exists():
        digest.update(b"D\0")
    else:
        assert path.is_file() and not path.is_symlink()
        data = path.read_bytes()
        digest.update(b"F\0" + len(data).to_bytes(8, "big") + data)
print(f"candidate paths: {len(paths)}")
print(f"SHA-256: {digest.hexdigest()}")
PY
```

No local commit, publication, deployment, or external write has occurred. Final
verification results and the newly computed fingerprint are reported in the
handoff after the last mutation. A fresh independent Tier-3 review remains the
next gate before owner acceptance.
