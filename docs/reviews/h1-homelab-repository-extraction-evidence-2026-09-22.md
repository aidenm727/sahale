## Fingerprint recipe

Read the manifest above in its exact order. For each row, emit UTF-8 bytes
`tree<TAB>status<TAB>path<TAB>value<LF>` with `tree` equal to `S` or `H`.
For added or modified paths, `value` is the lowercase SHA-256 hex digest of
the file's exact bytes. For deleted paths, `value` is the literal `DELETED`;
verify that the working-tree path is absent. The candidate fingerprint is the
lowercase SHA-256 hex digest of the concatenated row bytes. Use the Sahale
checkout and its sibling `homelab` tree as roots. Before hashing, confirm the
Sahale `HEAD` equals the baseline above, its changed-path/status set equals the
S rows, and every file in the Homelab tree equals the H rows. This recipe
includes the exact bytes of this evidence record and has no current fingerprint
value embedded in those bytes.
